## 🏛️ Portfolio Architecture & Standards

Every project in this repository adheres strictly to the **PLAN -> BUILD -> VALIDATE -> DEPLOY** methodology and contains:
1. **Source Code (`src/`)**: Clean, modular, type-safe Python implementation.
2. **Test Suite (`tests/`)**: 100% automated test coverage with deterministic offline mocks for zero-cost execution.
3. **Coach Notes (`docs/coach-notes.md`)**: A complete 360-degree beginner-friendly guide covering core concepts, architectural decisions, tradeoffs, real-world business use cases, and interview preparation.
4. **Engineering Run Report (`docs/run-report.md`)**: Autonomous execution log, risk mitigation, and token economics.
